## 后台赋能 ✅ 已实装（v0.2②，官方身份级机制）
- 每角色 `backSkill`（后台周期自动施放）+ `backPower`（后台强度基准 ≈0.6×atk，随星级缩放）
- 后台单位以 `BACK_CAST_SPD_FACTOR=0.4` 降速档进行动条，首次施技延后一个周期
- 后台不可被敌人选中、不吃能量、不耗战技点、被动不适用；`ally` 目标的赋能正常治疗/增益前台
- 位置：`characters.ts` backSkill/backPower；`engine.ts` BACK_CAST_SPD_FACTOR；`battle-build.ts` buildBackerUnit

## 战斗引擎现状
- 行动条制：AV=10000，出手间隔 = AV/速度
- **行动值倒计时 ✅（v0.2⑥）**：双方每次行动（含后台施技）-1，追击/反击/神君/dot 不消耗；预算 = stages 的敌方行动上限（⚠️14/18/20，难度拨盘）× Σ存活权重 / Σ存活敌方权重（后台 ×0.4），随减员动态重算——与旧敌方行动计数一阶等价；官方为固定预算约 100，切换需整体重校准；剩余行动值接口 = BattleResult.ticks
- 胜负：清空敌人胜；行动值耗尽未清场或我方全灭判负
- 伤害 = effAtk×倍率×(1-def/(def+320))×暴击×(0.95~1.05)；减伤上限 80%；护盾先吸收
- 已实装机制：dot(触电/灼烧)/引爆、神君、反击、击杀再动、追击、治疗光环、开战护盾、荆棘、击杀叠攻、攻击叠攻(火力风暴潮 onHitAtk，上限 5 层)、后台支援、策略核爆(当头一棒)/自伤(风暴骑士)
