- 经济采用云顶式近似（刷新2金/经验4金4exp/利息10:1封顶50），官方未公开的数值不再追查，全部登记 docs/开发进度.md §四
- 敌人难度公式按官方实现：难度 = 基础 + 策略(银0/金3/彩6) + 遭遇档(0/10/20/30) + 特殊加成；当前以"每条金策略敌人+4%"近似换算

- 美术保持"色块+名字+图标"简约风，官方亮紫主题；角色立绘不可用（版权）
- 每步发版走 tag → CI Release；平衡验证不过（bot 胜率出带，断言 15~98%）不发布
