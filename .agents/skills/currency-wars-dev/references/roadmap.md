# v0.2+ 开发路线（按三轮调研修订的优先级）

## v0.2 八步（按序执行，每步可独立发版）
1. **官方商店概率表 + 等级上限 10**：改 `stages.ts` 的 `SHOP_ODDS`/`MATCH_CONFIG.maxLevel`，同步 expToNext 设计与 bot（工作量最小）
2. **后台角色自动参战 + 后台强度属性**：官方身份级机制。CombatUnit 增加 back 强度维度；后台单位按 spd 行动自动施放弱化版技能；羁绊/装备的"前台强度/后台强度"词条落地
3. **投资策略三选一节点**：`stages.ts` 节点序列加入 strategy 节点；先实现 20 条代表性银/金策略（数据驱动，效果走 TeamFlags/回调）
4. **角色池扩到 24+ 并按官方费用校准**：优先补官方 1-2 费角色（停云/青雀/黑塔/艾丝妲已有），每角色设计前台/后台赋能
5. **星徽机制**：装备=加入羁绊(计数+1)+专属增益；奖励/策略掉落
6. **行动值倒计时**：用 AV 累计（100/speed）替代"敌方行动次数上限"，战斗时限对双方统一
7. **晋升词缀难度**：难度数值化（基础+词缀组合），先做 10 个词缀（沉重脚步/额外打击/复仇心切/免死金牌/应激反应/灼热轰炸/皮糙肉厚/软弱无力/决战在即/能量逃逸）
8. **超频模式 / 投资环境概念股 / 对手公司主题 / 专家顾问**

## 设计决策记录（勿反复）
- 经济采用云顶式近似（刷新2金/经验4金4exp/利息10:1封顶50），官方未公开的数值不再追查
- 敌人难度公式按官方实现：难度 = 基础 + 策略(银0/金3/彩6) + 遭遇档(0/10/20/30) + 特殊加成
- AI 对手与"阵容推荐"功能以社区 S 级阵容为模板（见规则详解 §24）
- 词缀强度避免"必须重开"级（NGA 实战分级为平衡参照）
- 美术保持"色块+名字+图标"简约风，官方亮紫主题；角色立绘不可用（版权）
- 每步发版走 tag → CI Release；平衡验证不过（bot 胜率出 60~85%）不发布

## 长期方向
赛季化更新模板（官方规律）：新角色 2~6 名 + 新羁绊/阵营 + 新策略/环境 + 平衡调整 + 难度上限提升 + 新词缀
成就系统「预期收益」可作为进阶目标玩法（总经济/阵容价值/难度战斗/收集类）
