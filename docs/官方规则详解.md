## 1. 对局结构

- 一局 = **3 个位面**，依次面对不同敌人与首领，击败第三位面首领获胜
- 节点类型：**战斗节点 / 遭遇节点 / 奖励节点 / 补给节点 / 首领节点 / 投资环境节点 / 投资策略节点**
  - 奖励节点：三选一奖励（装备/金币/角色等）
  - 补给节点：获取装备（角色可"携带"装备）
  - 投资环境：开局类整局增益（详见 §7）
  - 投资策略：节点推进类增益三选一，**分银/金/棱彩三档品质**（详见 §8）
- **战斗为倒计时/行动值制**：须在有限行动值内消灭全部敌人；基础行动值约 100（投资策略「延迟收益」提及"战斗开始100行动值后"）；「决战在即」词缀会增减节点倒计时 ±30/20；「时间刺客」攻击削减 7 点倒计时
- 超时未清场 → 扣除小队生命值；生命归 0 → 对局结束
- **两种模式**：
  - 标准博弈：完整 3 位面；晋升点 = 1500 基础 + 每难度 5%（上限 80%）+ 额外 2700
  - 超频博弈：快速模式，晋升点 = 1000 + 每难度 5%（上限 80%）+ 额外 1500
- 双周积分奖励 18000 封顶；通关评价：剩余生命 ≥70 → 职级 +3；≥40 → +2；<40 → +1；失败不降级

## 2. 经济系统

| 项目 | 官方数值 |
|---|---|
| 利息 | 每 10 金币 +1，**50 金币封顶（+5）**；部分投资策略可突破上限（如利息上限提升至 9、每回合利息 +2） |
| 免费刷新 | 每个节点自动免费刷新 1 次商店；可锁定商店防止自动刷新 |
| 手动刷新 | 花费金币（⚠️ 社区惯例 2 金币，官方未公开） |
| 买经验 | 花费金币购买（⚠️ 数值未公开；投资策略「成长基金」在 9 级时给 40 金币可作参照） |
| 基础收入 | 每场战斗结束获得基础金币（⚠️ 数值未公开） |
| 连胜奖励 | 连胜获得额外金币（⚠️ 数值未公开；投资策略「嘴硬」战败可维持连胜数） |

## 15. 角色赋能与机制示例（4.4 公告原文摘录）

赋能 = 前台/后台不同的角色专属效果，是本玩法最深的一层：
- **千冶•刃**（2费 星核猎手/燃血/减益）：后台——战前自动打造临时进阶装备，穿满 3 件则随机升格特权；前台——开战放终结技展开结界，行动消耗生命攻击，前台队友攻击为其充能施放额外战技
- **姬子•启行**（3费 列车同行/领航员）：领航员——选择一名列车同行角色：加入其流派羁绊（计数+1）、获得其第一件装备效果、【星穹列车】形态与技能随所选角色变化
- **远坂凛**（1费 战技点/命运圣杯）：前台/后台围绕【宝石能量】与 Archer 连携攻击；联动开启前以「投影」形态进商店（不可升星）
- **专家顾问**：桑博/刃/佩拉/姬子（4.4 新增），成为顾问后离开原羁绊分级（如贝洛伯格 2/4/6 → 2/4）；停云终结技使目标队员获得等同停云 60% 后台强度的前台强度；加拉赫激活 2/4/6/9 击破时给【以太钻头】
- 角色有**推荐装备列表**（4 件）：「好运令牌」从中选一、「装备跟踪」可追踪、「客制化服务」让随便骰子出推荐装备、「入职礼包」给携带 2 件装备的角色发推荐进阶装

**其它角色机制关键词**：忆灵（召唤物，长夜月/遐蝶等，人海战术按"角色与忆灵数量之和"计数）、布洛妮娅两种羁绊形态、昔涟诗篇收集、黑天鹅占卜牌、白厄 7 羁绊、火花【顶级流量】赋能等级、绯英赋能叠伤、银狼LV.999 的骇客改件 Pro/Max/普通三档、万敌 2→1 费调整。

## 16. 投资策略深度机制（棱彩档 + 关键佐证）

**行动值系统的直接佐证**（策略原文）：
- 剩余价值：战斗结束每剩余 30 行动值 → 1 金币（最多 4）
- 成本控制：每剩余 10 行动值 → 回 1 生命（最多 8）
- 前段发力：开战行动提前 40%，每经过 1 行动值降 1%
- 更快，更幸运：每经过 20 行动值在另一名角色上重复加速效果

**难度数值系统**：简单模式(难度-3)、难度修改器(-4)、伟大征服(敌人难度+连胜数)、成就要求难度 50/100/120/140/160 战斗胜利——**敌人难度是 0~160+ 的数值**。

- 藏一手：致死免疫并变 40 生命+80 金

- 佩佩客串：每完美通关佩佩自动穿一件进阶装

## 19. 关键系统定论（修正此前理解）

1. **团队规模 = 等级(上限10) + 财富宝钻数**（成就"团队规模 12/13"与宝钻 +1、控制规模"最大等级变7级"互证）；最大等级 10，规模可达 13
2. **敌人难度是数值**（0~160+），晋升职级解锁更高难度与词缀组合
3. **4 星存在**：3★ 之上还有 4★（超光速提拔可临时 1→4★；"4星其实更强但极其苛刻"）
4. **战斗结算统计**：伤害统计排名（榜样类词缀/策略）、伤害为 0 判定（气氛组）
5. **完美通关**概念（佩佩客串/命运礼物按完胜加速）
6. **遭遇节点**：与战斗节点并列，倒计时与奖励不同（武装突入：遭遇奖励×2）

## 23. 敌人难度计算公式（米游社攻略，重要）

**敌人难度 = 基础难度 + 策略难度加成 + 遭遇等级难度加成 + 特殊难度加成**

| 因子 | 数值 |
|---|---|
| 策略加成 | 每个白银策略 +0；每个黄金策略 **+3**；每个棱彩策略 **+6** |
| 遭遇档位 | 遭遇其一 +0；遭遇其二 **+10**；遭遇其三 **+20**；遭遇其四 **+30** |
| 特殊 | 棱彩策略「伟大征服」+当前连胜数；命运圣杯羁绊试炼 +30 |

基础难度在选关时可见（如 A8-42 = 基础 112）。成就任务推荐选关（一般情况，三棱彩+第三位面遭遇四 = +48）：

| 目标难度 | 所需基础难度 | 推荐关卡 |
|---|---|---|
| ≥100 | ≥52 | A7-4 |
| ≥120 | ≥72 | A8-11 |
| ≥140 | ≥92 | A8-26 |
| ≥160 | ≥112 | A8-42 |
